# mcp-github-practice

## 環境需求

- [Node.js](https://nodejs.org/) `>= 18`（建議使用目前的 LTS 版本）
- npm（隨 Node.js 一起安裝）

確認版本：

```bash
node -v
npm -v
```

## 安裝步驟

1. Clone 這個 repo：

   ```bash
   git clone https://github.com/a0920006091/mcp-github-practice.git
   ```

2. 進入專案目錄：

   ```bash
   cd mcp-github-practice
   ```

3. 安裝相依套件：

   ```bash
   npm install
   ```
